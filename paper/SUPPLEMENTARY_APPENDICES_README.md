# Supplementary Appendices

This directory contains extended results and supplementary figures for the JOSIS manuscript:

**"Benchmarking Large Language Models for Geolocating Colonial Virginia Land Grants"**

## Contents

- **APPENDIX_B_Extended_Results.md** – Comprehensive accuracy metrics, performance tables, cost-accuracy trade-offs, processing time analysis, token usage statistics, and professional GIS benchmark breakdown.

- **APPENDIX_C_Supplementary_Figures.md** – Error distribution plots, error maps (contact sheets), marginal cost analysis, and latency-accuracy tradeoff visualizations.

## Purpose

These appendices were moved from the main manuscript to the supplementary repository per peer review feedback (JOSIS R1) to reduce paper length while preserving full transparency and reproducibility. All tables and figures referenced in the main text are available here.
